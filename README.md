# Portafolio web · Josue Ramírez Borja

Sitio personal desarrollado con **HTML y CSS**, como práctica de estructura de páginas, estilos y presentación de contenido.

## Abrir el proyecto

Desde la carpeta del repositorio:

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

Visita [Portafolio.html](http://127.0.0.1:5500/Portafolio.html). También puedes abrir el archivo directamente en el navegador.

## Estructura

- `Portafolio.html`: contenido y estructura.
- `Estilos.css`: presentación.
- Recursos gráficos del repositorio: imágenes de la página.

## Alcance

Versión estática de un portafolio. No requiere npm, una API ni una base de datos. Los archivos de audio y video mencionados en el proyecto original no se distribuyen por su tamaño; esas referencias pueden requerir que incorpores tus propios recursos.

Mi presentación y el catálogo actualizado de proyectos están en [mi perfil de GitHub](https://github.com/JosueRBorja).
